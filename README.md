# THE ASCENT BLUEPRINT — برنامه روزانه

سایت حرفه‌ای ساخته‌شده از روی طرح اصلی «برنامه روزانه» (فایل: `uploads/Vitto Season Planner¹.png`).

## ✨ ویژگی‌ها

- 🎨 بازسازی دقیق هویت بصری طرح: گرادیان بنفش-سرمه‌ای، متن اسطوخودوسی، چک‌باکس‌ها و خط‌چین‌ها
- 📅 **پلنر روزانه تعاملی** — همان صفحه طرح، به‌صورت زنده: چک‌باکس‌های قابل تیک، فیلدهای نوشتن و تاریخ شمسی
- 💾 ذخیره‌سازی خودکار محتوا در مرورگر (localStorage)
- 🖨️ دکمه «چاپ / ذخیره PDF» برای پرینت برنامه روز
- 📱 کاملاً واکنش‌گرا (ریسپانسیو) — موبایل، تبلت و دسکتاپ
- 🌙 تم تاریک بنفش با انیمیشن‌های اسکرول، شمارنده آمار و منوی شیشه‌ای

## 📁 ساختار

```
├── index.html              ← صفحه اصلی
├── assets/
│   ├── css/style.css       ← استایل‌ها
│   ├── js/main.js          ← تعاملات (تاریخ شمسی، ذخیره، چاپ)
│   └── img/planner-original.png ← طرح اصلی (تصویر مبدأ)
└── uploads/                ← فایل‌های آپلودی (طرح اصلی PNG)
```

## 🚀 اجرا

```bash
python3 -m http.server 8000
# یا هر سرور استاتیک دیگری
```
