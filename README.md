# برنامه روزانه — The Ascent Blueprint

تبدیل طرح «برنامه روزانه» به یک وب‌اپ فارسی، راست‌چین و واکنش‌گرا با حال‌وهوای نئونی بنفش/مسی.

## امکانات

- **تقویم واقعی**: تاریخ امروز به فارسی، نوار هفته‌ی واقعی (شنبه تا جمعه) و تقویم ماهانه‌ی قابل ناوبری برای انتخاب هر روز.
- **برنامه امروز**: لیست تسک/تودو با چک‌باکس قابل تیک‌زدن، ساعت اختیاری، افزودن/ویرایش/حذف.
- **اولویت کارها** و **اهداف امروز**: در پایین برنامه‌ی امروز، هرکدام با افزودن/ویرایش/حذف و قابلیت تیک‌زدن.
- **اولویت امروز**: سه ردیف تمرکز (مطالعه، تسک رشد فردی، تمرین/یادداشت) با خط‌چین و قابلیت افزودن/ویرایش/حذف.
- **درس‌هایی که امروز گفتم**: بخش یکدست کاغذ خط‌دار برای نوشتن خوش‌خط؛ ذخیره‌ی خودکار.
- **ذخیره‌ی خودکار** در `localStorage` برای هر روز به‌صورت جداگانه.
- **نوار پیشرفت** کلی روز (تکمیل‌شده / کل کارها).

## اجرا

صفحه یک فایل استاتیک است:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس در مرورگر به `http://localhost:8080` بروید.

یا فقط `index.html` را مستقیم در مرورگر باز کنید (تمام امکانات بدون نیاز به سرور کار می‌کند).
