# THE ASCENT BLUEPRINT — برنامه روزانه (سایت شخصی)

سایت شخصیِ ساخته‌شده از روی طرح اصلی «برنامه روزانه» — همان عکس `uploads/Vitto Season Planner¹.png`، به‌صورت زنده و تعاملی.

## ✨ ویژگی‌ها

- 🎨 بازسازی دقیق هویت بصری طرح: گرادیان بنفش-سرمه‌ای، متن اسطوخودوسی، چک‌باکس‌ها و خط‌چین‌ها
- 📅 **پلنر روزانه تعاملی** — همان صفحه طرح: چک‌باکس‌های قابل تیک، فیلدهای نوشتن و تاریخ شمسی
- 💾 ذخیره‌سازی خودکار محتوا در مرورگر (localStorage)
- 🖨️ دکمه «چاپ / PDF» برای پرینت برنامه روز
- 📱 کاملاً واکنش‌گرا (ریسپانسیو) — موبایل، تبلت و دسکتاپ
- 🚫 بدون فرم ورود / عضویت / خبرنامه — فقط پلنر

## 📁 ساختار

```
├── index.html              ← صفحه اصلی (خود پلنر)
├── assets/
│   ├── css/style.css       ← استایل‌ها
│   ├── js/main.js          ← تعاملات (تاریخ شمسی، ذخیره، چاپ)
│   └── img/planner-original.png ← طرح اصلی (تصویر مبدأ)
└── uploads/                ← فایل‌های آپلودی (طرح اصلی PNG)
```

## 🚀 اجرا

```bash
python3 -m http.server 8000
# یا هر سرور استاتیک دیگری
```
