# برنامه‌ی روزانه — صفر تا قله

وب‌اپ برنامه‌ریز روزانه‌ی شخصی، **فارسی (RTL)**، با تم تیره‌ی نئونی — کاملاً **آفلاین** و در یک فایل واحد.

## اجرا

کافیست روی `index.html` دوبار کلیک کنید. هیچ نصب، سرور یا اینترنتی لازم نیست (بدون CDN و بدون هیچ درخواست شبکه‌ای).

## شخصی‌سازی برند

در انتهای `index.html` داخل تگ `<script>` این خط را عوض کنید:

```js
const BRAND = "MY BRAND";
```

نام در هدر، فوتر و عنوان صفحه به‌صورت خودکار به‌روز می‌شود.

## فونت (اختیاری)

برای فونت وزیرمتن، فایل `Vazirmatn.woff2` را کنار `index.html` یا در پوشه‌ی `assets/` بگذارید.
اگر نبود، به‌صورت خودکار به فونت سیستمی فال‌بک می‌شود.

## امکانات

- تاریخ شمسی و روز هفته‌ی خودکار با `Intl.DateTimeFormat('fa-IR-u-ca-persian')` — چیپ امروز درخشان می‌شود
- ذخیره‌ی خودکار هر روز در `localStorage` (کلید بر اساس تاریخ)؛ روزهای قبل حفظ می‌شوند
- جدول ۱۲ ردیفی برنامه، اولویت کارها (۵ چک‌باکس، اولی قرمز)، اهداف امروز (۴ خط)، اولویت امروز (مطالعه / تسک رشد فردی / تمرین‌–‌بدنسازی)
- نوار پیشرفت از روی ۸ چک‌باکس؛ در ۱۰۰٪ پیام «🏔 قله فتح شد!» و شدت‌گرفتن نور قاب
- شمارنده‌ی «روز صفر تا قله» از اولین استفاده
- چاپ با تم روشن (`@media print`)
- پشتیبان‌گیری و بازیابی JSON
- ریسپانسیو (زیر ۹۰۰ پیکسل تک‌ستونه)، آسمان پرستاره‌ی متحرک و میکروانیمیشن‌ها

## داده‌ها

همه‌چیز فقط در مرورگر خودتان ذخیره می‌شود. پاک‌کردن داده‌های سایت = پاک‌شدن برنامه‌ها؛ برای نگهداری از دکمه‌ی «پشتیبان‌گیری» استفاده کنید.
